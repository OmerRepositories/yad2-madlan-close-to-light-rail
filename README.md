# קרבה לרכבת הקלה – תוסף Chrome ליד2 ולמדלן

על כל מודעה ברשימת התוצאות מוצגים תגים:

`🚆 450 מ׳ · ~7 דק׳ הליכה · תחנת דיזנגוף` · `💰 ₪28,800 למ״ר · −12% מהחציון` · `⭐ שווה בדיקה`

- **רכבת**: ירוק עד 600 מ׳ · צהוב עד 1.5 ק"מ · אפור רחוק יותר. `≈` = הערכה לפי שכונה/עיר. לחיצה פותחת מסלול הליכה בגוגל מפות.
- **מחיר למ"ר**: מחיר ÷ שטח, מושווה לחציון של המודעות שבדף (ירוק = זול מהחציון, אדום = יקר).
- **שווה בדיקה**: מודעה שעומדת בכל התנאים שהגדרת (ברירת מחדל: עד 800 מ׳ מהרכבת וגם 10% מתחת לחציון מחיר למ"ר בדף). הכרטיס מסומן במסגרת כתומה.

## התקנה (מצב מפתחים)

1. פתח `chrome://extensions`
2. הפעל **Developer mode**
3. לחץ **Load unpacked** ובחר את התיקייה `lightrail-ext`
4. אם התוסף כבר מותקן: לחץ על כפתור הרענון שלו ורענן את דף האתר

## הגדרות

לחץ על אייקון התוסף בסרגל הכלים של Chrome (אפשר לנעוץ אותו דרך תפריט הפאזל). השינויים נשמרים אוטומטית ומתעדכנים בדף מיד:

- **מחיר מקסימלי למ"ר (₪)** – למשל 30000. 0 או ריק = לא פעיל.
- **זול מחציון הדף ב-% לפחות** – 0 = לא פעיל.
- **לדרוש קרבה לרכבת** + **מרחק מקסימלי במטרים**.
- **להדגיש מודעות שוות** – כיבוי מסיר את המסגרת והתג (התגים האחרים נשארים).

כל התנאים שמופעלים צריכים להתקיים יחד. אפשר להפעיל רק מחיר, רק רכבת, או שילוב.

## איך זה עובד

- **תחנות**: נשלפות מ-OpenStreetMap (Overpass) בשאילתת bbox מהירה, נשמרות שבוע, ונטענות מראש כשהדפדפן עולה.
- **חישוב עצלן**: כתובות מחושבות רק למודעות שנראות על המסך (ועד ~700 פיקסלים מתחתיו), והמודעות שנגללו אליהן אחרונות מטופלות קודם.
- **מטמון**: כתובת שכבר חושבה נשמרת, ולכן ביקור חוזר מיידי.
- **גיאוקוד**: Nominatim (OSM), עד בקשה אחת בשנייה לפי מדיניות השירות.
- **מרחק**: קו אווירי לתחנה הקרובה; זמן הליכה = מרחק × 1.3 ÷ 80 מ׳ לדקה.

## הערות

- יד2 ומדלן משנים את מבנה הדף מדי פעם. אם חילוץ הכתובת, המחיר או השטח מפסיק לעבוד, הפונקציות `extractQueries` ו-`extractPriceSqm` ב-`content.js` הן המקום לכוונן.
- החציון מחושב על המודעות שנטענו בדף, ולכן מודעות ממקומות שונים באותו דף ישוו אחת לשנייה. הכי מדויק בחיפוש של עיר או שכונה אחת.
- תחנות בבנייה או חדשות מאוד עלולות לא להופיע ב-OSM.
